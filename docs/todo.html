Your own machine settles half of this. A Core Ultra 9 285H with an Arc iGPU and the Intel NPU but no discrete GPU cannot run an 8B encoder at System One speed — and a decision model that takes seconds is not a decision model, it is a slow LLM call with fewer options. So no local clm-serve.

Worth knowing either way: Laya covers more than you have been using it for. A calibrated yes/no in 0.1–0.3 s on CPU is exactly the shape of a trading signal gate and of grading a language-app answer against fixed outcomes. CLM only wins when you need to rank hundreds of candidates — which, across your current projects, is nothing yet.
