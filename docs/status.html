What was measured

Document versus code — the code wins

mcp.nix declares exactly two servers and lists memory, filesystem, github, playwright, svelte and mcp-nixos as legacy to be pruned. Four of those six are live at user scope right now. Meanwhile firecrawl, which the module does declare, is not registered at user scope at all — it sits in local scope under ~. The module's intent and the live configuration have fully diverged, and that is the single finding this whole project turns on.

Resolved 13 Nov: the module's CLI-first intent is the truth and the live config is the drift. github, filesystem and memory go; playwright stays, because the design and web-design-playbook skills drive a real browser. The deeper fix is mcp-declarative — until Nix writes the server list on activation rather than a script anyone can forget, this divergence simply happens again.
