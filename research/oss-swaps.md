# oss-swaps
**Question:** Which of Chatwoot, Cap, AppFlowy, OpenProject, VoiceStudio and OpenHiggsField can a four-person NixOS web studio self-host for free, and what quietly turns paid?
**Answer:** OpenProject (GPL-3.0) and Cap (AGPL-3.0) are the only two that are genuinely free to self-host at four people. OpenProject still has no nixpkgs package, and Cap's own Docker Compose is a heavy install. Chatwoot is MIT except for an `enterprise/` folder that needs a paid licence in production. AppFlowy's self-host is now one free seat per instance, so it fails at four people. VoiceStudio and Open Generative AI (the real "OpenHiggsField" candidate) are desktop apps or API front ends and are not team services.
**Confidence:** medium, because licences, pricing and activity were read from official pages and the GitHub API, but nixpkgs presence was only partly confirmed.
**What would change our decision:**
- The OpenProject NixOS module lands in nixpkgs (the wiki says 26.11). Then OpenProject becomes a one-line `services.openproject.enable`. Also, if the studio keeps Jira, none of this is needed.
- Chatwoot's `enterprise/` folder turns out to hold features the studio needs (SLA, audit logs, SSO). Or Chatwoot's free Hacker cloud tier (2 agents) is dropped. Either would settle Chatwoot one way or the other.

## Findings

1. **Chatwoot** (chatwoot/chatwoot; it is a customer-support inbox, not a project tool)
   - Licence: the root licence is MIT Expat, copyright Chatwoot Inc 2017-2026 ([LICENSE](https://raw.githubusercontent.com/chatwoot/chatwoot/develop/LICENSE)). Everything under `enterprise/` is under a separate Enterprise License. That licence permits production use only with a paid subscription covering your seat count ([enterprise/LICENSE](https://raw.githubusercontent.com/chatwoot/chatwoot/develop/enterprise/LICENSE)). The GitHub API reports the licence as NOASSERTION/Other ([API](https://api.github.com/repos/chatwoot/chatwoot)). I found no relicensing announcement. WHICH FEATURES LIVE IN `enterprise/` is UNVERIFIED.
   - Linux/nixpkgs: it is a Ruby on Rails app. I found no nixpkgs package or module. `pkgs/by-name/ch/chatwoot/package.nix` returns 404 on master ([check](https://raw.githubusercontent.com/NixOS/nixpkgs/master/pkgs/by-name/ch/chatwoot/package.nix)), and a web search found nothing. The realistic route is Docker on NixOS. NIXPKGS ABSENCE IS ONLY PARTLY VERIFIED, and I have no 25.05 or 26.05 data.
   - Cost: self-hosting needs web servers, workers, PostgreSQL, Redis, an email service and object storage ([architecture](https://developers.chatwoot.com/self-hosted/deployment/architecture)). Minimum RAM and CPU are UNVERIFIED, because the page gives none. Hosted prices are per agent per month: Hacker $0, Startups $19, Business $39, Enterprise $99 ([pricing](https://www.chatwoot.com/pricing)). Hacker is free for up to 2 agents, with 500 conversations a month, live chat only, 30-day retention, and no Teams, automation or Help Center. Four agents therefore cannot use the free tier. The cheapest hosted option for four is Startups at about $76 a month.
   - Maintainer: Chatwoot Inc, a company. Last push was 2026-11-25, with 40.5k stars and not archived ([API](https://api.github.com/repos/chatwoot/chatwoot)).
   - Fit: only useful if the studio wants a client-support inbox. It is not a replacement for Jira, and it is poor value at four people.

2. **Cap** (CapSoftware/Cap, a Loom alternative)
   - Licence: AGPL-3.0 for everything, except the `cap-camera*` and `scap-*` crates (MIT) and third-party components under their own licences. Copyright is Cap Software, Inc. No `ee` or enterprise directory is mentioned ([LICENSE](https://raw.githubusercontent.com/CapSoftware/Cap/main/LICENSE)). AGPL section 13 applies only if you modify it and serve it to others. The GitHub API reports NOASSERTION, which is just the multi-licence layout ([API](https://api.github.com/repos/CapSoftware/Cap)).
   - Linux/nixpkgs: it has a Linux desktop app, and the release notes say AppImage capture works on NixOS ([releases](https://github.com/CapSoftware/Cap/releases)). I found no nixpkgs package. My one guessed path returned 404, and I did not run a search.nixos.org query, so treat it as UNVERIFIED. The server runs from Docker Compose.
   - Cost, self-host: you need MySQL, S3-compatible storage (bundled MinIO, or R2), a media server and a reverse proxy. A 2-CPU host processes one video at a time, and the media server uses 768 MB per job. It needs a full repo clone to build. Support is community-only ([self-hosting](https://cap.so/docs/self-hosting)). The docs do not say whether Pro features are gated when self-hosting. UNVERIFIED.
   - Cost, hosted: the free plan is personal use only, with 5-minute shareable links and 25 links a month. Cap Pro is $12 per user a month, or $8.16 billed annually, which is about $33 to $48 a month for four users. The Desktop License is $29 a year or $58 lifetime per user ([pricing](https://cap.so/pricing)). This is a free tier with limits, and the limits bite for team use.
   - Maintainer: Cap Software, Inc, a company. The latest release is 0.6.3 on 11 Nov 2026, with three releases in about a month ([releases](https://github.com/CapSoftware/Cap/releases)). The last push was 2026-11-25 and it has 25.5k stars ([API](https://api.github.com/repos/CapSoftware/Cap)).
   - Fit: reasonable for async client walkthroughs, and the hosted $12 per user is cheap. Self-hosting it on the Contabo VPS competes with the VPS's other work, because of video processing.

3. **AppFlowy** (AppFlowy-IO/AppFlowy, a Notion alternative; the studio already uses Obsidian)
   - Licence: the client is AGPL-3.0 ([API](https://api.github.com/repos/AppFlowy-IO/AppFlowy)). The server side has changed:
     - AppFlowy-Cloud (AGPL-3.0) was archived by its owner on 11 Sep 2026. It says not to build from it, and that new server features are only in prebuilt Docker images ([repo](https://github.com/AppFlowy-IO/AppFlowy-Cloud)).
     - The replacement is AppFlowy-SelfHost-Commercial, distributed solely under the AppFlowy Self-Hosted Commercial License. It runs a closed-source codebase ([repo](https://github.com/AppFlowy-IO/AppFlowy-SelfHost-Commercial)). This is a real relicensing away from open source for the server.
   - Linux/nixpkgs: yes, the package `appflowy` exists at `pkgs/by-name/ap/appflowy/package.nix`. It repackages the upstream prebuilt binary, is marked AGPL-3.0-only, and covers x86_64-linux only ([source](https://github.com/NixOS/nixpkgs/blob/nixos-unstable/pkgs/by-name/ap/appflowy/package.nix)). The version in each channel is UNVERIFIED (one aggregator said 0.15.1 on unstable). There is no NixOS server module.
   - Cost, self-host: the free tier is one user seat per instance, plus up to 3 guest editors, unlimited workspaces and version history. This is the finding you asked about. Four members means a paid self-hosted plan, and I could not find those prices ([SelfHost-Commercial](https://github.com/AppFlowy-IO/AppFlowy-SelfHost-Commercial)).
   - Cost, hosted: Personal is $0, with 100 MB storage, 7 MB uploads and 7-day history. Pro is $12 per member a month billed annually, or $16 monthly, so four people is $48 to $64 a month. Guest editors are free ([pricing](https://www.appflowy.com/pricing)).
   - Maintainer: AppFlowy-IO, a company. The desktop repo was last pushed 2026-11-15 and has 79.5k stars, so it is not abandoned ([API](https://api.github.com/repos/AppFlowy-IO/AppFlowy)).
   - Fit: no. The self-host path is no longer open source and caps at one seat, and Obsidian already covers the notes need.

4. **OpenProject** (opf/openproject; a project-management tool, so it overlaps with Jira)
   - Licence: GPL-3.0, copyright OpenProject GmbH 2012-2026. It is derived from ChiliProject and Redmine (GPL-2.0 or later) ([COPYRIGHT](https://raw.githubusercontent.com/opf/openproject/dev/COPYRIGHT)). The GitHub API confirms GPL-3.0 ([API](https://api.github.com/repos/opf/openproject)). I found no carve-out in the licence file. The Enterprise add-ons are gated by a token inside the same GPL codebase, and the add-ons sample includes Gantt PDF export, team planner, portfolio management, SSO, LDAP and SCIM ([pricing](https://www.openproject.org/pricing/)). Whether the gated code is separately licensed is UNVERIFIED.
   - Linux/nixpkgs: it is not upstream in nixpkgs yet. The NixOS wiki says the package and `services.openproject` module are "not yet upstream" and will be available in NixOS 26.11. The old request (issue #252956) was closed as not planned ([wiki](https://wiki.nixos.org/wiki/OpenProject), [issue](https://github.com/NixOS/nixpkgs/issues/252956)). The module file path I guessed returns 404 on master. Until then, run it with Docker, or use the out-of-tree module that the wiki does not link (UNVERIFIED). That means 25.05 and 26.05 do not have it, and unstable's state is UNVERIFIED.
   - Cost, self-host: Community is free with no user minimum. The docs call for 4 cores and 4 GB RAM for the app, 2 CPUs and 4 GiB for the database, 20 GB disk, and PostgreSQL 16 or later with pg_trgm, btree_gist and unaccent. Memcached is not needed on one server ([requirements](https://www.openproject.org/docs/installation-and-operations/system-requirements/)). That is roughly 8 GB of RAM in total, a large share of a Contabo VPS.
   - Cost, hosted: paid plans start at €5.95 per user a month (Basic), but with a 25-user minimum, so four people cannot buy a plan. There is a 14-day cloud trial that is deleted if you do not upgrade ([pricing](https://www.openproject.org/pricing/)). Self-hosted Community is therefore the only free route at four people.
   - Maintainer: OpenProject GmbH, a company, with the OpenProject Foundation. The last push was 2026-11-25, with about 121k commits and 17.7k stars ([repo](https://github.com/opf/openproject), [API](https://api.github.com/repos/opf/openproject)).
   - Fit: the only genuine Jira replacement here, and free at four people. But it is heavy to run and has no NixOS module until 26.11, so it only makes sense if the crew actually wants to leave Jira.

5. **VoiceStudio** (picked debpalash/VoiceStudio, formerly OmniVoice-Studio; the name is ambiguous, and other repos such as shuv1337/VoiceStudio and silentlamp/voicestudio are forks)
   - Licence: the app is AGPL-3.0, "including commercial use under its terms" ([README](https://github.com/debpalash/VoiceStudio), [API](https://api.github.com/repos/debpalash/VoiceStudio)). A paid closed-source build, VoiceStudio Pro, adds a commercial licence for client work. The default OmniVoice model weights are CC-BY-NC (non-commercial), and each model has its own licence ([README](https://github.com/debpalash/VoiceStudio)). Some blogs say MIT, which is wrong. Commercial use of generated audio is therefore a per-model question, and a web studio shipping client voiceovers needs to check the model licence before using any default.
   - Linux/nixpkgs: Linux x64 is supported via a curl installer, AUR, Snap, .deb and AppImage, and from source with `nix develop .#fhs` ([README](https://github.com/debpalash/VoiceStudio)). I found no nixpkgs package (the guessed path `voicestudio` returned 404, UNVERIFIED).
   - Cost: it is a local desktop app with no seats. It works on CPU but slowly, and uses NVIDIA CUDA, experimental AMD ROCm, Metal or Vulkan. A Contabo VPS has no GPU, so it would run on the crew's laptops. Pro price is UNVERIFIED.
   - Maintainer: two named core people (Palash Debnath and Shimul Debnath), not a funded company as far as I can see. The repo was created 2026-04-09 and last pushed 2026-11-24, with about 118k stars and 8.4k commits ([API](https://api.github.com/repos/debpalash/VoiceStudio)). It is very active but very young, and the star count is unusually high for its age, which I did not investigate.
   - Fit: only if the studio actually produces voiceover work. Run it on a laptop, not the VPS.

6. **OpenHiggsField** (I cannot name one official repo; there are several unrelated ones, and none is affiliated with Higgsfield AI. I picked Anil-matcha/Open-Higgsfield-AI, now renamed Open-Generative-AI, as the main candidate)
   - Licence: MIT ([repo](https://github.com/Anil-matcha/Open-Higgsfield-AI), [API](https://api.github.com/repos/Anil-matcha/Open-Higgsfield-AI)). Other repos use the same name: wide-trace/open-higgsfield (openhiggsfield.ai) has no LICENSE file and one contributor, TechBeme/open-higgsfield is MIT, and lucataco/open-source-higgsfield is Apache-2.0 and runs on ComfyUI ([search results](https://www.kensa.cc/blog/open-higgsfield-ai)). That second-hand claim is from a blog and is UNVERIFIED against the repos themselves, except for the Anil-matcha one.
   - Linux/nixpkgs: Linux is supported through Docker, a web build (`npm run dev`), and an AppImage or .deb. I found no nixpkgs package (UNVERIFIED).
   - Cost: cloud generation needs a paid Muapi.ai key, so it is not free to use. Local mode runs sd.cpp on CPU, or Wan2GP on an NVIDIA or AMD GPU (about 8 GB VRAM for the small Wan model), desktop only. Muapi prices are UNVERIFIED.
   - Maintainer: an individual (Anil-matcha). The last push was 2026-11-24, with about 36k stars and 542 commits ([API](https://api.github.com/repos/Anil-matcha/Open-Higgsfield-AI)). The owner's other activity and funding are UNVERIFIED.
   - Fit: a front end for paid image and video APIs, which breaks the "pay only for Claude, domain, VPS" rule unless the crew uses local models on a GPU.
